Additional Information Module
----------------------------

This module creates an "Additional Information" content type with the following fields:

- Time required for joining from the date of receiving offer letter (in days)
- Kindly describe significant contributions where you have worked? (Long Text)
- What makes you suitable for the post you have applied? (Long Text, max 500 words)
- Have you been debarred or punished for adopting unfair means in any Examination by the Institution/Board/University? (Yes/No list)
  - If Yes (Details)
- Have you ever been involved in any administrative malpractice? (Yes/No list)
  - If Yes (Details)
- Have you ever been involved in any financial irregularity? (Yes/No list)
  - If Yes (Details)
- Were you ever discharged or dismissed from any previous employment? (Yes/No list)
  - If Yes (Details)
- Is there any pending or contemplated disciplinary proceedings against you? (Yes/No list)
  - If Yes (Details)
- Application (entity reference)

Fields are created automatically when the module is installed.
